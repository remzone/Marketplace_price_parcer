🛍️ Marketplace Parser API Documentation

Эта страница поможет тебе использовать API парсера маркетплейсов. Поддерживаются: Ozon, Wildberries, Yandex Market.

POST /search

Поиск по одному маркетплейсу.

ПараметрТипОбязательныйОписание
querystring✅Название, артикул или ссылка
search_typestringНет (default: name)name, article или link
scrollsintНет (default: 1)Количество скроллов
max_cardsintНет (default: 3)Кол-во карточек
marketplacestringНет (default: ozon)ozon, wildberries, yandex

Пример запроса cURL (по названию)

curl -X POST http://localhost:8000/search \
-F "query=iphone 16 pro" \
-F "search_type=name" \
-F "scrolls=2" \
-F "max_cards=5" \
-F "marketplace=ozon"

Пример запроса cURL (по артикулу)

curl -X POST http://localhost:8000/search \
-F "query=1272546013" \
-F "search_type=article" \
-F "marketplace=ozon"

Пример запроса cURL (по ссылке)

curl -X POST http://localhost:8000/search \
-F "query=https://www.ozon.ru/product/..." \
-F "search_type=link" \
-F "marketplace=ozon"

POST /api/search-all

Запуск поиска по всем маркетплейсам сразу (только по названию).

ПараметрТипОбязательныйОписание
querystring✅Название товара
search_typestringНет (default: name)Всегда "name"
scrollsintНет (default: 1)Количество скроллов
max_cardsintНет (default: 3)Кол-во карточек

Пример запроса cURL

curl -X POST http://localhost:8000/api/search-all \
-F "query=iphone 16 pro" \
-F "scrolls=2" \
-F "max_cards=5"

Пример ответа

{
  "success": true,
  "total_products": 9,
  "results": [
    {
      "marketplace": "Ozon",
      "name": "Apple iPhone 16 Pro",
      "price": "149 990 ₽",
      "link": "https://..."
    },
    ...
  ]
}

GET /last-results-parse

Перепарсинг уже скачанных HTML-файлов (только Ozon).

Параметры URL

ПараметрТипОбязательныйОписание
marketplacestringНет (default: ozon)Поддерживается только ozon

Пример запроса cURL

curl -X GET "http://localhost:8000/last-results-parse?marketplace=ozon"

💡 Общие моменты

  • Фронтенд расположен по адресу / и работает из папки frontend/.
  • Все HTML-файлы сохраняются в data/{marketplace}/html_snapshots/.
  • Все действия логируются в logs/server.log.
  • Сервис использует Selenium с профилем Chrome для обхода антибот-защит.
